# 朴鱼

做工程类公司的经营管理，自己写工具解决自己遇到的问题。

## 我在做什么

给一家工程类公司设计并落地了一套经营管理系统（私有仓库）：合同、分包、项目、收支、发票、人员工资串成一条数据链。

核心不在界面，而在**数据关系设计**——合同是唯一源头，向下既生成收入链（开票 → 收款），
也生成成本链（分包 / 生产 / 运营分摊），最终汇总成单个项目的毛利。
其中最关键的一层是「产值 × 约定收款比例 = 应收」，它把「钱该什么时候到」从记忆变成了可计算的数字。

技术选型的约束来自使用者：必须双击就能用、不装环境、数据留在本机。
所以后端只用 Python 标准库 + SQLite，前端是单文件页面，用 PyInstaller 打包成 exe。

## 作品

### [数据体检 · data-checkup](https://github.com/puyu-l/data-checkup)

从上面那套系统里抽出来的通用工具，与具体业务无关，任何记账场景都能用。

- **10 条一致性校验规则**，全部由「合同 → 开票 → 收款 → 成本 → 毛利」的关系模型推导而来
- **穿透查询**：从任意一笔流水追回它的合同、发票与成本科目
- **纯 Python 标准库**，零依赖，拿到就能跑
- 示例数据埋了 18 处典型错误，跑一遍就能看懂每条规则在防什么

[在线演示报告 →](https://puyu-l.github.io/data-checkup/)
